Kreeda-Ankana
Sports Ground and Match Management Application

Kreeda-Ankana is an Android-based mobile application developed using Android Studio and Kotlin to simplify sports ground booking, team coordination, and sports activity management within villages and local communities. The application provides a digital platform for managing sports-related activities efficiently and helps reduce the challenges associated with manual ground booking systems.

Project Overview

Traditional sports ground management in many villages and communities is handled manually, which often leads to:

Booking conflicts
Poor coordination between teams
Lack of organized scheduling
Difficulty in maintaining sports records
Time-consuming communication processes

Kreeda-Ankana addresses these problems by providing a centralized Android application where users can digitally manage sports ground bookings and sports coordination activities.

Objectives

The main objectives of the project are:

To digitize sports ground booking systems
To reduce manual scheduling conflicts
To improve communication between sports teams
To provide a user-friendly Android interface
To organize sports activities efficiently
To demonstrate Android application development using Kotlin
Features
Digital Sports Ground Booking

Users can enter team details and reserve sports ground slots digitally.

Booking Confirmation

The application validates user input and displays booking confirmation instantly.

User-Friendly Interface

The application is designed with a simple and easy-to-use interface using XML layouts.

Sports Coordination Support

The platform helps improve coordination among teams and players.

Scalable Architecture

The application architecture supports future integration with Firebase and cloud synchronization systems.

Problem Statement

Many sports grounds in villages and local communities are managed manually without any organized booking system. Multiple teams often attempt to use the same ground simultaneously, causing confusion and scheduling conflicts. There is no centralized digital platform for managing sports bookings or coordinating sports activities efficiently.

Proposed Solution

Kreeda-Ankana provides a digital solution for sports ground management by enabling users to reserve sports slots through a mobile application. The system improves organization, minimizes conflicts, and supports better sports coordination using Android technology.

Results

The application successfully demonstrates a prototype Android-based sports management system. The developed system improves organization, reduces manual effort, and provides a scalable platform for future enhancements such as realtime synchronization and leaderboard systems.
